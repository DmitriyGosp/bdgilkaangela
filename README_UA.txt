ЯК ОТРИМАТИ DOMK.EXE БЕЗ ВСТАНОВЛЕННЯ PYTHON НА СВОЄМУ ПК

1. Увійдіть на https://github.com або створіть безкоштовний обліковий запис.
2. Створіть новий репозиторій (New repository), наприклад DOMK-builder.
3. Завантажте в репозиторій усі файли з цієї папки, включно з прихованою папкою .github/workflows.
   Важливо: файл збірки має лежати за адресою .github/workflows/build-windows.yml.
4. Відкрийте вкладку Actions у репозиторії.
5. Виберіть workflow «Build DOMK Windows EXE» та натисніть Run workflow.
   (Якщо workflow автоматично запустився після завантаження файлів, дочекайтеся його завершення.)
6. Відкрийте завершений запуск зі статусом зеленої галочки.
7. Унизу сторінки в розділі Artifacts завантажте DOMK-Windows-EXE.
8. Розпакуйте ZIP. Усередині буде DOMK.exe.

На комп'ютері, де запускається DOMK.exe, Python встановлювати не потрібно.
Для роботи програми потрібен Windows 10/11. Excel як програма не обов'язковий — програма працює з файлами .xlsx.

ПРИМІТКА
Це налаштування автоматичної збірки, а не вже скомпільований EXE.
EXE створюється серверами GitHub Actions під Windows. Після кожної зміни domk_app.py збірку можна запустити знову.
